# Features

Features are individual items on roadmap.
We should create it working with agent to make sure all dependencies are created

A example prompt for creating a feature spec:
```bash
"Find the nex phase on specs/reoadmap.md and make a branch, ask me about the feature spec.
Create:
- A new directory YYYY-MM-DD-feature-name under specs for this feature work
- in there: 
    - `plan.md` as a series a numbered task groups
    - `requirments.md` for the scope, decisions, context
    - `validation.md` for how to know the implementation succeded and can be merged
Refer to spec/mission.md and specs/tech-stack.md for guidance.

Important: You must use your AskUserQuestion tool, grouped on these 3, before writing to disk.
```

Good feature specs should have:

## Aproach

## Sequence of work

## How to validate sequence of success

Once we have it we can implement it. best co clear context/start new featue
```bash
Implement the next task group
```
