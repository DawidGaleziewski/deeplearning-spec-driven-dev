1.Create the environment:Terminal.Run your initialization and installation commands (e.g., uv init followed by uv add <packages>) inside your WSL terminal to generate the .venv folder.2.Open Interpreter Settings:PyCharm Settings.In PyCharm, click on the Python version/Interpreter text in the bottom right corner of the window and select Add New Interpreter, or click Configure Python Interpreter in the yellow warning banner if it appears.3.Select WSL:Environment Type.Choose WSL from the left-hand menu. Ensure your correct Linux distribution (e.g., Ubuntu-24.04) is selected, and click Next.4.Choose 'Existing':Configuration.On the left side of the next screen, select Virtualenv Environment. Then, change the Environment radio button at the top from "New" to Existing.5.Use the visual file browser:Path Selection.Do not type or paste the path manually. Instead, click the folder icon next to the Interpreter field.6.Select the Python file:Locate Executable.Navigate through the visual folder structure to your project directory. Expand .venv ➡️ bin, and explicitly select the file named python. Click OK.7.Create and Index:Apply Settings.Click Create. Wait a few moments for PyCharm to finish "Indexing" (visible in the bottom right corner) before you start coding, so your imports are recognized.How to verify: Anytime you set up a new project, you know you have done it correctly when PyCharm stops displaying red squiggly lines under standard packages like pandas or openai.
