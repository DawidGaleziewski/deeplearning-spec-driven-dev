# Prompt: Validate a Completed Course

Use the `course-validator` skill in Validate mode for: **<course ID or title>**.

Read the official curriculum, the course spec, my course materials, and the
validation rubric. If the spec is missing or incomplete, prepare it before the
interview.

Run an adaptive interview in short conversational rounds. Test:

- the central mental model;
- important distinctions and trade-offs;
- application to a new scenario;
- failure modes and limitations;
- transfer to a relevant engineering project.

Ask no more than five questions now, then wait for my answers. Do not show model
answers before I respond. After the complete interview, score the evidence and
either synchronize a pass with the roadmap or create focused remediation tasks.
