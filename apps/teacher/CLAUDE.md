# Learning Repository Guidance

This repository uses a spec-driven course-validation workflow.

Before starting, validating, remediating, or completing a course, read and obey
`AGENTS.md` and `CONSTITUTION.md`. Treat `roadmap.md` as the completion source of
truth and `validation/rubric.md` as the pass standard.

Use the `course-validator` skill whenever the user:

- starts or resumes a roadmap course;
- says a course is finished;
- asks to test, quiz, assess, or validate their learning;
- asks to update course progress or the roadmap;
- asks what should be learned next.

For an interactive learning-governor session, the project agent is defined at
`.claude/agents/learning-governor.md`.

Never check a roadmap item without a passed course spec and a corresponding
learning-ledger entry.
